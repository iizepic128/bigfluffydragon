# NeO 777 coding agent notes

Read `CODEX_HANDOFF.md` and `README.md` before changes. Treat this folder as the project root.

- Start with `npm install` and `npm run build`; report/fix any errors before adding new work.
- Maintain the original NeO 777 identity and all original assets. Avoid copying third-party game branding or copyrighted assets.
- Preserve existing browser save compatibility and HUD/minimap controls.
- Physics changes must respect collision boundaries and remain performant in a normal desktop browser.
- Keep meaningful changes small and testable; explain tests actually run and those not run.
